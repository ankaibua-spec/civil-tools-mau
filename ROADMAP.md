# Public roadmap

## 0.2.x - Community validation

- Collect reproducible AutoCAD and BricsCAD reports for all seven commands.
- Add automated checks for CSV edge cases and command contracts.
- Confirm text encoding behavior in supported Windows CAD versions.
- Improve signed-offset handling after agreeing on alignment-side conventions.

## 0.3 - Survey workflow quality

- Configurable label height, precision, prefix, and layer names.
- Station formatting such as `1+234.567`.
- Optional point identifiers during CSV import.
- Safer large-selection progress and cancellation behavior.

## 0.4 - Interoperability

- Documented LandXML or field-book exchange proposal, subject to community review.
- Localized command prompts without changing stable command names.
- A compatibility table based only on verified community reports.

Roadmap items are proposals, not promises. Public issues and reviewed pull requests determine scope. The project will not add telemetry, license checks, a hidden updater, private customer data, or code copied from commercial repositories.
